📋 Leyenda
Network ACL: Control de tráfico a nivel de SUBRED (Stateless)
Security Group (SG): Control de tráfico a nivel de INSTANCIA (Stateful)
Subnet Pública: Acceso directo a Internet via Internet Gateway
Subnet Privada: Sin acceso directo a Internet

🔐 Detalles de Configuración de Seguridad

🛡️ NETWORK ACLs (Nivel de Subred)

Características:

  • Stateless: Debes configurar reglas de entrada Y salida
  • Aplicación: A TODA la subred
  • Evaluación: ANTES que Security Groups
  • Orden: Se evalúan por número de regla (menor primero)

Ejemplo ACL Subnet Pública:

INBOUND:
100: HTTP (80) desde 0.0.0.0/0 - ALLOW
110: HTTPS (443) desde 0.0.0.0/0 - ALLOW
120: SSH (22) desde 203.0.113.0/24 - ALLOW
32767: ALL Traffic - DENY (regla por defecto)
OUTBOUND:
100: HTTP (80) hacia 0.0.0.0/0 - ALLOW
110: HTTPS (443) hacia 0.0.0.0/0 - ALLOW
120: Ephemeral ports (1024-65535) hacia 0.0.0.0/0 - ALLOW
32767: ALL Traffic - DENY (regla por defecto)

🔒 SECURITY GROUPS (Nivel de Instancia)

Características:

  • Stateful: Si permites entrada, la respuesta está permitida automáticamente
  • Aplicación: A instancias EC2 específicas
  • Evaluación: DESPUÉS de Network ACLs
  • Por defecto: DENY todo inbound, ALLOW todo outbound

Ejemplo Security Groups:

SG1 (Web Servers):
INBOUND:
- HTTP (80) desde 0.0.0.0/0
- HTTPS (443) desde 0.0.0.0/0
- SSH (22) desde SG-Admin
OUTBOUND: All traffic (por defecto)
SG2 (App Servers):
INBOUND:
- Puerto 8080 desde SG1
- SSH (22) desde SG-Admin
OUTBOUND: All traffic (por defecto)
SG3 (Database):
INBOUND:
- MySQL (3306) desde SG2
- SSH (22) desde SG-Admin
OUTBOUND: All traffic (por defecto)

⚡ Flujo de Evaluación de Tráfico

Orden de evaluación del tráfico ENTRANTE:
1️⃣ Internet Gateway
2️⃣ Network ACL de la Subnet (INBOUND)
3️⃣ Security Group de la Instancia (INBOUND)
4️⃣ Llega a la instancia EC2

Orden de evaluación del tráfico SALIENTE:
1️⃣ Instancia EC2 envía respuesta
2️⃣ Security Group (OUTBOUND) - Si stateful, permite automáticamente
3️⃣ Network ACL (OUTBOUND) - Debe estar explícitamente permitido
4️⃣ Internet Gateway
